# Hon WTC11 Cardiomyocyte (v0)

TF Perturb-seq (CRISPRi) in WTC11-derived cardiomyocytes from the Hon Lab.

The v0 set is the **Hon Lab internally processed** dataset. It was not run through the TFP3 CRISPR pipeline.

| Cell line | WTC11 (human iPSC) → cardiomyocyte |
